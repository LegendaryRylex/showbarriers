# Show Barriers

Barrier blocks are invisible in vanilla unless you hold one. Show Barriers draws them all the time, as a see-through red-tinted cube marked with the barrier sign, so map borders, hidden walls and invisible floors are easy to spot while building or exploring.

Walls and floors of barriers render as one clean surface, with no inner faces between neighbouring blocks.

Client-side only: install it on your own game, servers do not need it.

NeoForge, Minecraft 26.1.2.
